# 0003 回帰判定のしかた

## 正解と検出の割り当ては COCO の評価と同じ方式

confidence の高い検出から順に、まだ割り当てていない同じクラスの正解のうち IoU が最大のものへ割り当てる。IoU が `iou_threshold`（既定 0.5）未満なら割り当てない。1つの正解には TP を1つしか割り当てず、残りの検出は FP になる。

before と after の差分の対応づけ（ADR 0002）は IoU の大きい順で決めるが、こちらは confidence の順で決める。正解との照合では、確信度の高い検出を優先するのが物体検出の評価で一般的なため。

## PASS / FAIL は正解の物体ごとに決める

正解の物体に TP が割り当てられれば PASS、割り当てられなければ FAIL とする。before と after の組み合わせで maintained（PASS → PASS）・improved（FAIL → PASS）・regressed（PASS → FAIL）・unresolved（FAIL → FAIL）に分類する。

## FP は遷移の表に入れない

FP（正解の無い検出）は正解の物体に結び付かないため、遷移の表には入れず、フレームごと・モデルごとに件数と内容を記録する。precision と recall は TP・FP・FN から計算し、分母が 0 のときは null にする。

## 評価の対象

- 正解アノテーションの `frames` に載っているフレームだけを評価する。載っていないフレームは件数（`unannotated_frames`）だけを記録し、PASS としても FAIL としても数えない。
- `objects` が空のフレームは「何も写っていないのが正解」として評価し、検出はすべて FP になる。
- 正解アノテーションの sha256・幅・高さが推論結果と違う場合と、正解を付けたフレームが推論結果に無い場合は、エラーで止める。
